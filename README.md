# Care Nova - Premium Home Healthcare

Care Nova is a premium home healthcare website designed to provide world-class medical care at your doorstep. This project features a luxury-themed, responsive user interface with bilingual support (English/Arabic) to cater to a diverse clientele in Dubai/UAE.

## 🌟 Key Features

*   **Premium Aesthetic:** Designed with a luxury gold and dark theme, featuring smooth gradients, glassmorphism effects, and animations.
*   **Fully Responsive:** Optimized for all devices, from large desktop screens to mobile phones.
*   **Bilingual Support (EN/AR):** Built-in language switcher that toggles text content and text direction (LTR/RTL) instantly.
*   **Interactive Booking System:** A clean, easy-to-use booking form with immediate feedback.
*   **Care Pathway Visualization:** A custom-designed, responsive timeline showing the 3 easy steps to get care.
*   **Direct Communication:** Floating buttons for quick access to WhatsApp and Phone calls.

## 🛠️ Technologies Used

*   **HTML5:** Semantic structure for better SEO and accessibility.
*   **CSS3:** Custom styling with CSS variables for color themes (`--gold-luxury`, `--black-primary`), responsive media queries, and animations.
*   **JavaScript:** Vanilla JS for handling language switching, form submissions, and UI interactions (accordion, mobile menu).

## 🚀 How to Run

Since this is a static website, you can run it easily:

1.  **Directly:** Simply double-click the `index.html` file to open it in your default web browser.
2.  **Local Server (Recommended):** Use a VS Code extension like "Live Server" or run a simple python server:
    ```bash
    python -m http.server 8000
    ```
    Then visit `http://localhost:8000`.
